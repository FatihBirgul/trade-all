# Onay sonrası tek kontrollü operasyon

Bu belge yetki değildir. Kullanıcının ayrı, açık 8006 + dokuz PWA dosyası + HMR + rollback onayı olmadan canlı adım çalıştırılmaz. Hazırlık tamamlandı; onay beklenir. Tüm komutlar PWA izole kökünden yürütülür. 8005/8007/Tailscale ayarları korunur. Operasyon öncesi diğer iş akışlarının yazma/restart yapmadığı doğrulanır; drift'te güvenli STOP.

1. RC ZIP/manifest, dokuz payload/current source hash'i,27 target guard ve envanteri, yeni runtime config/launcher/source mühürlerini yeniden doğrula. `node tools/promotion-apply.mjs` salt okunur varsayılandır. Aktif 8006 PID + CreationDate + executable + parent + cwd/env kimliğini `.artifacts/cutover/services-final.json` ve current-launch-safe.json ile karşılaştır. PID'yi sabit kabul etme; eşzamanlı değişiklikte eski kill komutunu kullanma.
2. Account identity'yi yalnız RAM'de önce/sonra karşılaştır; mevcut REAL/Exness-MT5Real50/USC gate'i koru. Beklenmeyen hesap/terminal veya arka plan supervisor varsa dur. Devam eden manuel analiz isteğinin tamamlanmasını bekle; bakım penceresinde yeni analiz başlatma. Stop işlemi Windows TerminateProcess/taskkill olduğundan graceful drain garantisi verilmez; sadece exact doğrulanmış backend PID ağacı hedeflenir, parent PowerShell veya porttan rastgele PID öldürülmez.
3. Ön yedek doğrulandı. Backend source archive3c8adb8, mevcut V5Runtime2.2.6 dependency sürümleri, current safe env ve failback-config/V2 snapshot hash'leri dondurulmuştur. Failback 14 kontrolle ayrı portta mevcut güvenli davranışı yeniden üretti. Eski interpreter/env değiştirilmez. Failback eski sürecin RAM'inin birebir kopyası değildir; doğrulanmış source/config yeniden başlatmasıdır.
4. Yalnız onay sonrası exact8006 sürecini durdur, portun boşaldığını doğrula. Beklenmeyen başka owner gelirse dur. Yeni bağımsız `.artifacts/cutover/runtime-venv/Scripts/python.exe` ile şu launcher'ı headless başlat (subprocess CREATE_NO_WINDOW veya PowerShell Start-Process -WindowStyle Hidden). UUID adlı taze manifest dosyası seç; var dosyayı kullanma:

```text
python.exe -B tools/cutover-runtime.py --release release/cutover/backend-3c8adb8 --config release/cutover/runtime-config.json --config-sha256 a5eea178328aa00c85ef650f0d9104deba5e828a89f1689a3e35e41e010054ae --manifest .artifacts/cutover/live-runtime-<UUID>.json --port 8006 --operator-approved-live
```

5. Health + port ownership/start time + fresh private manifest source_head/loaded/Python/NumPy/config/launcher hash kabulü yap. `node tools/cutover-live-accept.mjs --operator-approved <fresh-manifest-absolute-path>` dört metadata/manuel POST kontrolü sonrası UUID'li `release/cutover/live-backend-accepted-*.json` üretir. Gerçek hesap bakiyesi yok; test sermayesi açık10000USC. Dört spread UNAPPROVED/BLOCK ve null plan beklenir. Yeni runtime startup source/config/loaded kaydı olmadan PWA adımına geçme. Loaded fingerprint kapsamı Python function code'udur; globals/C extension için mutlak bellek ispatı değildir.
6. Backend kabulünden sonra 120 saniye içinde `node tools/promotion-apply.mjs --apply --operator-approved 1035c98420554d268c32f1a38bd0ed19379c18a67c53d93362edee216105b715 <backend-receipt-absolute-path>` çalıştır. Receipt PID/CreationDate, startup manifest ve source/NumPy kabulü olmadan araç BLOCK eder. Yaş aşılırsa backend kabulünü tekrar doğrula; receipt tarihini elle değiştirme.
7. Araç tam preflight, collision-free/hash doğrulanmış backup, dependency-first replacement ve App en son, ardından source hash ve smoke yapar. Tüm9 dosya tek atomik transaction değildir; HMR/yenileme bu onaylı bakım adımının parçasıdır. Beklenmeyen drift'te dur. NewsPanel kopyalanmaz, MarketChart tam beklenen hedef hash'i olmadan yazılmaz.
8. Canlı5173 ve Tailscale üzerinden dört sembol tek manuel Analyze; USC/hypothetical, güvenli ret, V2 unavailable/boş/var durumları, execution=false, plan null, no-order-controls, race/timeout ve chart/news regression kontrolü. Loopback browser mobil390×844 cihaz kabulü değildir. Eski SW için yalnız bu origin'e ait controller/asset sürümünü doğrula; gerekli cache temizliğini dar kapsamda uygula. Diğer origin/storage'a dokunma.
9. Yeni API veya UI smoke başarısızsa yalnız yeni başlatılan backend kimliğiyle durdur; doğrulanmış mevcut baseline failback-config ve V5Runtime executable ile `tools/cutover-failback.py --port 8006 --manifest <new-UUID-path> --operator-approved-live` headless başlat. PWA için APPLY backup receipt'iyle `--rollback --operator-approved <manifest-sha> <exact-backup-dir>` uygula. User drift/backup corruption varsa otomatik overwrite yok: STOP/CONFLICT_REQUIRES_REVIEW. Başarısızlıkta bridge/news/Tailscale/global paket değişikliği çözüm olarak kullanılmaz.

Onay bir kez backend cutover + PWA güncelleme/HMR + güvenli rollback denemesini kapsar. Hesap değişimi, spread onayı, emir veya yeni strateji geliştirme kapsamı yoktur. Gerçek cihaz testi olmadan fiziksel telefon PASS yazılmaz.
