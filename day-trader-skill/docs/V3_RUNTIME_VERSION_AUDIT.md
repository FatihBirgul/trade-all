# 8005 / 8006 / 5173 çalışma sürümü denetimi

10 Kasım 2026 salt-okunur denetim. Üç port localhost'ta dinliyor ve süreçler mevcut Windows kullanıcısına ait. 8005 ile 8006 Python 3.11 `uvicorn` süreçleridir; 5173 Node/Vite sürecidir. İşlem başlatılmadı, durdurulmadı veya yeniden başlatılmadı. 8005 OpenAPI başlığı `Trade AI MT5 Veri Sunucusu` 0.1.0, `/api/health` bağlantı alanı dönüyor. 8006 OpenAPI başlığı `Trade AI Forex` 0.2.0. 5173 Vite proxy yapılandırması `/engine` isteklerini 8006'ya yönlendiriyor; PWA dosyası değiştirilmedi.

8006 `/api/v5/analysis` ve 5173 `/engine/api/v5/analysis` XAUUSD/M15/H4 manuel POST istekleri aynı güvenli sonucu verdi: `forex-analysis-5`, `forex-unified-5.1`, `market_data_account_mode=REAL`, `account_currency=USC`, `DATA_UNAVAILABLE`, `INSUFFICIENT_DATA`, `legacy_signal=WAIT`, `execution_permission=false`, `missing candle without verified broker hours`. 8006 metadata salt-okunur sorgusunda tam alias `XAUUSDc`, sunucu `Exness-MT5Real50`, `broker_hours_status=UNVERIFIED_REAL_SESSION`, `broker_hours=null`, o anki `trade_mode=4` görüldü. Quote sorgusunda taze fiyat zaman damgası döndü. Bunlar 9 Kasım'daki trade mode veya seans çizelgesi değildir.

Çalışan 8006 yanıtının `public_code_sha256` değeri `c4ac3765e573af816376f2402de48a52a97f3978af4634fe06a5e2f1c615fc92` idi. Bu, `f96a74b` çalışma dosyalarının yeni modül eklenmeden önceki yerel içerik özetiyle eşleşti. Yeni çalışma dosyalarıyla hesaplanan özet farklıdır. Dolayısıyla çalışan süreç yeni bu teslim koduyla eşleşmiyor. Sürecin gerçek çalışma dizini ve yüklü Python modül yolu yalnız dışarıdan kesin belirlenemedi; commit SHA'sı da HTTP yanıtında yok. Yeni commit için durum **RUNTIME_VERSION_UNVERIFIED**. Mevcut servisler onaysız yeniden başlatılmayacaktır.

PWA proxy üzerinden gerçek manuel HTTP çağrısı ulaşıyor, fakat seans kanıtı eksik olduğundan canlı kabul tamamlanmadı. 8005/8006'nın aynı terminal örneğine bağlandığı ve PWA'nın tüm etkileşimli alanlarının yeni kodu kullandığı ayrıca doğrulanmadı.
