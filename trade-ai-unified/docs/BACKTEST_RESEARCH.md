# Historical research: actual retained OOS protocol

`market_ai.v2.walk_forward` is the original continuation train/select/freeze/test
implementation with explicit Forex dependencies/timebase. Training prefix/crop,
purge, inter-test embargo, deterministic objective/tie-break, frozen strategy/engine/
cost/data hashes, one held-out run per selected winner, separate fold accounts and
pooled-metric limitations are retained. It is not reimplemented as a second OOS
planner. Crypto product/ledger runner is replaced by an in-memory Forex callback;
no product DB, paper order engine, auto-paper or account mutation is imported.

Pure number/money/integer/summarize math is extracted from the pinned original
research.py with provenance. Its long-spot negative-equity restriction is explicitly
adapted: Forex gaps can produce negative equity and drawdown>100%, which remain in
the report. Dataset frames and nested metadata are owned; changing a returned rules
copy cannot alter a frozen experiment. V2 provenance verification is retained for
Forex execution frames; crypto acquisition and file writing were excluded.

Every setup is generated by the same V6 AnalysisEngine on closed historical prefixes;
V5 Time Machine stop-first/microstructure/risk/grid functions simulate next-open
entries and single exits. Costs are explicit0..100bps simulation assumptions, round-
trip commission and adverse entry/exit slippage.1% of then-current equity is the
risk cap; actual grid lot can be smaller. Open positions are marked at each closed
bar and remain open, not fabricated closed wins. Each fold starts flat with its own
10000-unit seed account. No continuous pooled equity is asserted.

Bounds: at most2000 bars/frame,6000 total,100 analyses/run and original OOS total
budgets; cadence is explicit. Zero-spread quotes are accepted only through an
explicit simulation-only flag; live quote defaults remain strict. Dataset/source/
license/effective broker rules and historical costs are declarations unless verified.
No trustworthy Forex dataset was acquired in this task; evidence remains
INSUFFICIENT_EVIDENCE and forward_validated=false. Win rate/expectancy/bootstrap
are historical mechanics, not a probability of future profitability.

Tests run actual multi-trade replay and two real OOS folds, deterministic reruns,
held-out mutation with identical first-fold selection hash, invalid/future/finality,
metadata ownership and adverse gap below zero equity. Source original381 tests
remain in the read-only source; only pure selected modules belong to this target.

## V7 continuation — current behavior

V7 extends the retained V2 train/select/freeze/test implementation in place.
validation_bars>0 adds a chronological validation tail separated from training by
purge. Training eligibility precedes validation selection; validation digest,
strategy/engine/risk/cost versions join frozen parameters. Default0 preserves the
old protocol and is not advertised as an independent validation split. Held-out
mutations preserve earlier frozen selection. Folds remain independent accounts;
no pooled compounded return/drawdown claim. Registry is bounded process memory,
32 results/8MB by default; identical experiment ID cannot acquire a different result.
GET experiments returns404 after eviction/restart. No production ledger/DB.

Dataset manifest includes exact source/venue/symbol/contract, per-frame counts,
ranges/basis/volume/hash, retrieval/timezone/license/use declarations and quality
checks. Trust is SYNTHETIC_TEST or DECLARED_HISTORICAL; SOURCE_VERIFIED and
POINT_IN_TIME_VERIFIED are reserved and cannot be claimed by input flags. Optional
non-overlapping rule epochs apply at historical event time, including session gaps;
coverage is explicit. Intrabar rule boundaries and financial contract changes across
open positions are refused pending a settlement model. Static rules are labelled
STATIC_RULES_HISTORY_UNKNOWN. Hash equality does not prove source/licensing.

Output includes direction/strategy/regime breakdown, average R, holding periods,
win/loss/expectancy/PF/drawdown/streaks, sample warnings and retained fixed-seed
bootstrap percentiles. Same-bar ambiguity is marked while explicit conservative
stop-first assumptions are scored; it is not observed intrabar execution. Synthetic
results stay INSUFFICIENT_EVIDENCE. Actual Forex edge/forward evidence remains absent.
