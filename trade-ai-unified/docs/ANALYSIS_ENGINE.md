# Canonical decision and response

Data acquisition/QC/identity and verified broker-session gate precede one cached
technical view, actual V2 regime/price action/patterns/MTF/confluence and explicit
Forex setup/router evaluation. Opposing price/strategy/MTF evidence waits without
levels. V5 broker planning and financial/daily risk may veto last. Levels and lot
are null on every invalid plan. A technically valid unsized candidate has
NOT_EVALUATED account eligibility; ELIGIBLE only means supplied risk inputs passed.

BUY_CANDIDATE/SELL_CANDIDATE, WAIT, NO_TRADE, INSUFFICIENT_DATA, MARKET_CLOSED,
STALE_DATA and PROVIDER_UNAVAILABLE remain separate from data/session/integration
health. PRIVATE_INTEGRATED means actual owned source components execute, not a
complete pattern catalogue or market validation. Failed calculations are explicit
and cannot silently fall back to a public-only result. Source SHAs, target code
hash, algorithm versions, snapshot and parameter hashes bind each report.

## V7 continuation — current behavior

Closed primary/MTF snapshots still drive the same analysis/route/plan flow. Default
live as-of is sampled after provider reads; historical as-of never advances. New
broker_schedule reports DECLARED/UNAVAILABLE, authenticated=false. The legacy
broker_hours_verified flag is only a compatible operator opt-in, never source
verification. Veto also clears candidate_direction to WAIT. Broker quotes off tick
grid are refused. Descriptive patterns cannot grant directional authority.
